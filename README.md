# ▶️ Running the Project

Clone the repository:

```bash
git clone https://github.com/otavioborgsm/fintech-react-w-ts.git
```

Access the project folder:

```bash
cd fintech-react-w-ts
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

# 🌐 Routes
